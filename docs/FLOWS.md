# Осмотрено: приложение в стиле Airbnb — логика и экраны

Как Airbnb, только вместо жилья — машины с пробегом. Отличие: каждая машина осмотрена, а полноценно смотреть машины может только зарегистрированный покупатель с оплаченным доступом.

---

## 1. Три уровня доступа

Что видит каждый уровень, решает сервер, а не приложение. Закрытые данные просто не приходят на устройство.

| Что видно | Гость (не вошёл) | Вошёл, без доступа | С доступом (990 ₽ / 30 дней) |
| --- | --- | --- | --- |
| Лента: марка, модель, год, город, цена | Да | Да | Да |
| Фото | Размыто | Первое фото | Все фото |
| Пробег, коробка, двигатель, расстояние | — | Да | Да |
| «Осмотрено» и дата осмотра | Да | Да | Да |
| Оценка состояния (жёлтая → зелёная) | — | — | Да |
| Отметки специалиста (пробег подтверждён, окрасы) | — | — | Да |
| Описание продавца, район | — | — | Да |
| Глубокий отчёт: история, толщиномер, чек-лист | — | — | До 30 машин в неделю |
| Записаться на просмотр, написать продавцу | — | — | Да |
| Избранное | — | Да | Да |

Нажатие на закрытое ведёт:

- гостя — к входу (Госуслуги, Т-ID, Сбер ID; один человек — один аккаунт);
- вошедшего без доступа — к оплате.

## 2. Покупатель

**Вкладки:** Поиск · Избранное · Просмотры · Сообщения · Профиль.

1. **Поиск.** Сверху строка «Какую машину ищете?», под ней категории с иконками: Все, Кроссоверы, Седаны, Хэтчбеки, До 1,5 млн, Свежие, Отличные (оценка 85+). Ниже — сетка карточек. Карточка как в Airbnb: большое фото, сердечко, «Осмотрено», название, год и пробег, цена, расстояние.
2. **Фильтры** (по строке поиска): марка или модель текстом, бюджет от–до, год от, кузов, коробка, радиус от вас.
3. **Страница машины:**
   - галерея;
   - название, город;
   - карточка продавца: «Продаёт собственник, личность подтверждена»;
   - главное: «Осмотрено 16.10», оценка, пробег подтверждён, владельцев;
   - описание, характеристики, отчёт осмотра;
   - внизу закреплено: цена и кнопка **«Записаться на просмотр»**.
4. **Запись на просмотр.** Выбор дня и времени (ближайшие 7 дней, слоты), комментарий продавцу. Заявка уходит продавцу, во вкладке «Просмотры» появляется статус «Ждёт подтверждения».
5. **Просмотры.** Ваши заявки: ждёт, подтверждён, отклонён, состоялся. У подтверждённого — адрес района и кнопка «Написать продавцу».
6. **Сообщения.** Переписка по каждой машине с продавцом, как в Airbnb.
7. **Покупка.** Договорились — продавец отмечает «Продано этому покупателю», у покупателя машина попадает в «Куплено». Онлайн-сделка с эскроу — следующий этап.

## 3. Продавец

**Вход:** Профиль → «Продать машину» (как «Сдать жильё» в Airbnb). Вход обязателен: собственник подтверждается через Госуслуги.

### Мастер размещения

| Шаг | Что делает продавец |
| --- | --- |
| 1. Откуда | Ссылка на своё объявление (Авто.ру, Авито, Дром) или «Заполню сам» |
| 2. Машина | Марка, модель, год, пробег, кузов, коробка, двигатель — подставляется из ссылки |
| 3. Фото | До 8 фото с телефона |
| 4. Описание и цена | Текст, цена, подсказка рыночной цены |
| 5. Где смотреть | Город и район |
| 6. Осмотр | Пункт осмотра и время, оплата 2 500 ₽, привязка карты для оплаты по итогу |

### После осмотра

Пункт вносит протокол через форму `/inspect`. Оценка от 60 — машина публикуется, ниже 60 — не публикуется, отчёт остаётся у продавца.

### Кабинет «Мои машины»

- статус объявления;
- заявки на просмотр: подтвердить или отклонить;
- сообщения;
- кнопки «Продано через приложение» (выбрать покупателя из тех, кто записывался) и «Снять с продажи».

### Деньги продавца

| Что | Сколько |
| --- | --- |
| Осмотр | 2 500 ₽ при записи |
| Размещение сейчас | 0 ₽ |
| Продал покупателю из приложения | 1%, от 5 000 до 30 000 ₽ |
| Снял, продал мимо или 60 дней без продажи | 2 990 ₽ |
| Подтверждённый обман | Снятие всех объявлений, блокировка |

## 4. Экраны

```
Вкладки:   Поиск   Избранное   Просмотры   Сообщения   Профиль
Окна:      Фильтры · Вход · Доступ (оплата) · Запись на просмотр
Страницы:  Машина · Переписка · Мастер «Продать» · Моя машина (кабинет продавца)
Сайт:      /inspect — протокол для пунктов осмотра; /terms, /privacy
```

## Бета: как пройти весь путь самому

1. Откройте https://autocheck-nu.vercel.app/app — при первом входе 4 экрана «почему Осмотрено».
2. «Я покупаю машину» → «Войти через Госуслуги» (тестовый вход: любой телефон и имя) → «Предоставить».
3. «Открыть полный доступ · 990 ₽» → «Перейти к оплате» → «Подставить тестовую карту» → «Оплатить». Деньги не списываются.
4. Откройте машину → «Записаться» → время → «Отправить заявку».
5. Чтобы побыть продавцом: Профиль → «Выйти» → войти с **другим** телефоном → «Продать машину» (6 шагов, тестовая оплата осмотра 2 500 ₽) → карточка «Моя машина».

Один телефон = один человек: с тем же номером на любом устройстве вы попадёте в тот же аккаунт.
Автопроверка всего пути: `python3 scripts/e2e_flow.py http://localhost:8787` (сервер: `PORT=8787 node server/dev.js`).
