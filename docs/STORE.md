# Тексты для App Store, Google Play и RuStore

## Название и подзаголовок

- **Название:** Осмотрено — проверенные авто (30 символов)
- **Подзаголовок (iOS):** Только осмотренные машины (до 30 символов)
- **Короткое описание (Google Play, RuStore, до 80 символов):** Машины с пробегом, которые уже осмотрели. Оценка состояния у каждой.

## Описание

Осмотрено — машины с пробегом, которые прошли живой осмотр до публикации. Ненадёжных объявлений здесь нет: машину с оценкой ниже 60 мы просто не публикуем.

КАК ЭТО РАБОТАЕТ
• Листайте ленту: вправо — в избранное, влево — дальше.
• У каждой машины есть дата осмотра и отметки специалиста: пробег, окрасы, ошибки.
• С пропуском покупателя видна оценка состояния — от жёлтого до зелёного — и глубокий отчёт: история по базам, толщина покрытия по деталям, чек-лист осмотра.
• Записывайтесь на просмотр прямо в приложении.

ЧЕСТНО ДЛЯ ВСЕХ
• Покупатели подтверждают личность — продавцу пишут настоящие люди, а не перекупы с десятками аккаунтов.
• Продавец платит за размещение, только если не продал машину через нас.
• Если обман подтвердится, объявление снимем, а продавца заблокируем.

ПРОДАТЬ МАШИНУ
Вставьте ссылку на своё объявление с другой площадки — заберём данные. Запишитесь на осмотр, и после него машина появится в ленте.

## Категории

- Основная: Покупки (iOS) / Автомобили и транспорт (Google Play, RuStore)
- Дополнительная: Образ жизни

## Возраст

18+ (оплата, сделки с автомобилями). В анкете: нет насилия, нет азартных игр, есть покупки.

## Для проверяющих (App Review notes)

Демо-вход: экран «Пропуск» → «Войти через Госуслуги» в бета-версии работает в тестовом режиме без реальной учётной записи. Оплата — тестовая, деньги не списываются. Удаление аккаунта: Профиль → Удалить аккаунт.

В iOS-версии пропуск не продаётся: приложение показывает статус пропуска, оформленного ранее.
