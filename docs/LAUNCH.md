# Осмотрено: что нужно для запуска простого приложения и сайта

Без перегруза: лента машин в стиле Tinder, только осмотренные машины с оценкой от 60, пропуск для покупателей, продавец платит по итогу.

Цены и сроки — гипотезы и ориентиры на октябрь 2026. Перед оплатой сверяйте с сайтами сервисов.

## 0. Что уже сделано и работает бесплатно

| Что | Где | Как устроено |
| --- | --- | --- |
| Приложение (веб-версия) | `/app` на сайте | Лента-свайпы, избранное, пропуск, глубокий отчёт с лимитом 30 в неделю, продажа по ссылке, профиль, удаление аккаунта |
| Сервер API | `/api/v1/...` на Vercel | Все правила модели: оценка от 60, пропуск, лимит, оплата продавца по итогу (1% или 2 990 ₽), блокировка за обман, ежедневное закрытие объявлений через 60 дней. 7 автотестов: `npm test` |
| Форма для пунктов осмотра | `/inspect` | Очередь машин → оценка, чек-лист, толщиномер → публикация или отказ |
| Оферты и политика ПДн (черновики) | `/terms`, `/terms-seller`, `/privacy` | Нужна проверка юристом, затем заполнить реквизиты |
| Тексты для магазинов | `docs/STORE.md` | Описание, ключевые слова, анкеты конфиденциальности |

**Ограничения бета-версии:**

- **Вход и оплата — в демо-режиме.** Кнопки Госуслуг, Т-ID и Сбер ID создают тестовую учётку, деньги не списываются. Чтобы включить настоящие, достаточно задать ключи в переменных Vercel: `YOOKASSA_SHOP_ID`, `YOOKASSA_SECRET`, а позже ключи провайдеров входа и `DEMO_AUTH=0`. Код под ЮKassa уже написан.
- **База пока в памяти** — встроенный PostgreSQL. Данные сбрасываются при перезапуске функции, а при нагрузке разные копии функции могут видеть разные данные.
  - Сделать её постоянной бесплатно: Vercel → проект → Storage → Create Database → Neon (Postgres), тариф Free. Переменная `DATABASE_URL` подставится сама, таблицы и демо-машины создадутся при первом запросе.
  - Neon хранит данные за рубежом. Для бета-теста на своих людях это допустимо, для реальных пользователей — переезд в Yandex Cloud или Selectel.
- **Бесплатный тариф Vercel (Hobby) — для некоммерческого использования.** Когда начнутся продажи, нужен тариф Pro или свой сервер в России.
- **Секретные ключи.** Задать в Vercel `SESSION_SECRET`, `PARTNER_KEY`, `ADMIN_KEY`, `CRON_SECRET` — без них работают демо-ключи.

## 1. Модель

Похоже на немецкий ImmoScout24: там за платный пакет Suchen+ платит ищущий жильё, а мы берём на себя качество предложения.

**Покупатель**

- Смотрит ленту без регистрации: фото, год, пробег, цена, «Осмотрено».
- Пропуск 990 ₽ на 30 дней даёт:
  - оценку состояния у каждой машины;
  - до 30 глубоких отчётов в неделю: история по базам, толщиномер, чек-лист;
  - запись на просмотр.
- Оформить пропуск можно только с подтверждённой личностью: один человек — один пропуск.

**Продавец**

1. Осмотр — 2 500 ₽. Публикуем только машины с оценкой от 60. Отчёт остаётся у продавца в любом случае.
2. Размещение — 0 ₽ сейчас, оплата по итогу:

| Итог | Сколько платит продавец |
| --- | --- |
| Продал через нас | Комиссия 1%, от 5 000 до 30 000 ₽ |
| Не продал за 60 дней, снял объявление или продал мимо | 2 990 ₽ |
| Подтвердился обман | Объявление снимаем, аккаунт блокируем по подтверждённой личности |

Карта продавца привязывается заранее. Списываем по оферте с сохранённой карты, а не держим блокировку: банки держат блокировку (холд) несколько дней, не 60. Например, у Яндекс Пэй — максимум 5 дней.

## 5. Магазины приложений

### App Store (iOS)

- **Аккаунт разработчика.** Apple Developer Program — $99 в год. Российская карта не принимается.
- **Платежи в России.** С апреля 2026 российские пользователи почти не могут платить в App Store: пополнение Apple ID с баланса телефона отключено. Монетизация через российский аккаунт разработчика фактически не работает. Рабочий путь — аккаунт на иностранное юрлицо: D-U-N-S, банковский счёт для выплат, проверка Apple занимает недели.
- **Правило 3.1.1.** Цифровой доступ — наш пропуск — по правилам Apple продаётся только через покупку в приложении. Поэтому iOS-версия в прототипе ничего не продаёт и никуда не ссылается: только показывает статус пропуска.
- **Правило 3.1.3(e).** Физические услуги — осмотр 2 500 ₽, плата продавца — можно оплачивать своей кассой и в iOS.
- **Правило 4.8.** Если вход через сторонний сервис, например Т-ID или Сбер ID, Apple требует ещё и «Вход с Apple». Исключение — государственные системы идентификации вроде Госуслуг. Для iOS делаем Госуслуги или вход по телефону.
- **Обязательно для публикации:**
  - удаление аккаунта в приложении;
  - ссылка на политику конфиденциальности;
  - анкета App Privacy;
  - скриншоты 6,7″ и 6,5″;
  - контакты поддержки;
  - тестовый аккаунт для проверяющих Apple.

### Google Play (Android)

- **Аккаунт разработчика** — разово $25.
- **Оплата в России.** Биллинг Google Play в России приостановлен, а цифровые подписки по правилам Google продаются через их биллинг. В Google Play выпускаем бесплатную версию, где пропуск оплачивается только на сайте. Перед публикацией уточнить актуальные правила Google для России.
- **Обязательно:**
  - анкета Data safety;
  - политика конфиденциальности;
  - удаление аккаунта: в приложении и по веб-ссылке;
  - закрытое тестирование: для новых личных аккаунтов — 12 тестировщиков в течение 14 дней.

### RuStore (основной канал для Android в России)

- Публикация бесплатная, можно как физлицо, ИП или юрлицо.
- Платные приложения и покупки в приложении поддерживаются. Как принимать оплату — через SDK RuStore или своей кассой — уточнить в правилах RuStore при регистрации.
- Свои пуши — RuStore Push SDK.

### Веб и PWA

Сайт с веб-версией приложения — главный канал продаж пропуска: там нет комиссии магазинов и их ограничений по оплате.

## 6. Юридический минимум

1. **ООО** (или ИП на старте). ОКВЭД 63.11 и 63.12 (порталы и обработка данных), 74.90.
2. **Оферты:**
   - для покупателя — пропуск, лимит, отказ, возврат;
   - для продавца — осмотр, оплата по итогу, комиссия, 2 990 ₽, блокировка за обман;
   - договоры с пунктами осмотра.
3. **Персональные данные:**
   - политика обработки и согласия;
   - уведомление в Роскомнадзор об обработке ПДн;
   - хранение в России;
   - не собирать лишнего: из Госуслуг и банковских ID берём только ФИО и признак подтверждения.
4. **Онлайн-касса и чеки** — 54-ФЗ, через платёжный сервис.
5. **Товарный знак** «Осмотрено» — подать в Роспатент, пока название свободно.
6. **Домен.** С 1 сентября 2026 регистрация и продление доменов .RU и .РФ требуют подтверждения через Госуслуги. Регистрируйте на юрлицо заранее.

## 8. Доступы, которые нужны разработке

Пароли не присылайте — только ключи и приглашения. Для начала хватит первых трёх пунктов.

1. **GitHub** — уже есть.
2. **Expo:** аккаунт на expo.dev, приглашение в организацию или токен `EXPO_TOKEN` — для сборок iOS и Android в облаке.
3. **Yandex Cloud:** сервисный аккаунт с ролью editor на отдельный каталог (ключ JSON).
4. **ЮKassa:** shopId и секретный ключ тестового магазина, потом — боевого.
5. **Агрегатор данных по VIN:** API-ключ.
6. **App Store Connect:** API-ключ (Issuer ID, Key ID, файл .p8) с ролью App Manager.
7. **Google Play:** сервисный аккаунт JSON. **RuStore:** API-ключ.
8. **DNS домена:** доступ к записям, чтобы привязать api.osmotreno.ru и сайт.
9. **Т-ID / Сбер ID / ЕСИА:** client_id и секреты после подписания договоров.
