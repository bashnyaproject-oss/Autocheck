# Осмотрено

Прототипы сервиса проверки и продажи автомобилей с подтверждённым осмотром.

| Путь | Что это |
| --- | --- |
| `/` | Стартовая страница со ссылками на оба прототипа |
| `/check` | Микросервис «Осмотрено»: проверка по номеру, VIN или ссылке, сравнение объявлений, карта пунктов осмотра, тарифы |
| `/market` | Полное приложение: роли покупателя, продавца, дилера и сервиса подбора, сеть пунктов осмотра, онлайн-сделка, аукцион |

Сайт статический, без сборки: каждая страница — один HTML-файл со встроенными стилями и скриптом. Vercel раздаёт папку как есть (`vercel.json` включает адреса без `.html`).

Локально: открыть `index.html` в браузере или запустить `npx serve .` в корне.

Все данные в прототипах — демонстрационные.
