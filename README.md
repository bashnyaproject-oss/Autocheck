# Осмотрено

Прототипы сервиса проверки и продажи автомобилей с подтверждённым осмотром.

| Путь | Что это |
| --- | --- |
| `/` | Стартовая страница со ссылками на оба прототипа |
| `/check` | Микросервис «Осмотрено»: проверка по номеру, VIN или ссылке, сравнение объявлений, карта пунктов осмотра, тарифы |
| `/market` | Полное приложение: роли покупателя, продавца, дилера и сервиса подбора, сеть пунктов осмотра, онлайн-сделка, аукцион |

Сайт статический, без сборки: каждая страница — один HTML-файл со встроенными стилями и скриптом. Vercel раздаёт папку как есть (`vercel.json` включает адреса без `.html`).

Локально: открыть `index.html` в браузере или запустить `npx serve .` в корне.

Все данные в прототипах — демонстрационные.

## Загрузка объявлений по ссылке

`/api/parse?url=…` — серверная функция Vercel (`api/parse.js`). Открывает объявление Авто.ру, Авито или Дрома и достаёт название, год, цену, пробег, двигатель, коробку и фото (JSON-LD → Open Graph → текст страницы). Если площадка отвечает капчей, функция возвращает `{ok:false, blocked:true}`, и мастер продажи просит дописать год, пробег и цену вручную. Марку и модель в этом случае берём из самой ссылки.

## Карта

На сайте подключается Яндекс Карты 2.1 (синие кластеры, красная выбранная метка, «Вы здесь»). Ключ — бесплатно на developer.tech.yandex.ru («JavaScript API и HTTP Геокодер»), вставить в `YMAPS_KEY` в общем скрипте страниц. Если Яндекс не загрузился, включается Leaflet с картой OpenStreetMap. Местоположение берётся из браузера: расстояния до машин и пунктов пересчитываются, пункты сортируются по близости.
